## 指南分支 review（文本契约，不是实际安装）

| 输入状态 | 必需决策 |
| --- | --- |
| 未知账户/已有连接 | 先发现当前上下文，只问无法确定的重要目标，不预填六项、不跨账户猜测 |
| 无满足需求的 Tag | 说明缺口；用户选择未发布源码时固定完整 commit，不静默取 main、不混资源 |
| 首次安装且能力可用 | 完整包、PRIVATE、真实绑定、创建与启用分开 |
| 已有目标且含定制 | 读 ID/版本/文件/绑定，比较差异，更新实际目标，冲突询问，不同名重建 |
| 旧包不可读/无更新能力 | 报限制，停止覆盖，不假定无定制、不编造导入能力 |
| 已满足需求 | 只验收，不重复创建或改配置 |
| 写入结果未知 | 先查真实目标现状再决定重试 |
| 权限拒绝/待登录 | 不绕过，独立工作可继续，报告精确阻碍与用户下一步 |
| 工具可见/创建回执/只读成功 | 不冒充启用、技能运行或 Linux 运维验收；缺必需证据保持 partial |
